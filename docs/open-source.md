# Source availability and publication

XGrid is free software under GPL-2.0-or-later. The source for a release is this
repository at the release tag, including the tracked core and its patch record.

See:

- [Source availability](legal/source-availability.md)
- [Licensing](legal/licensing.md)
- [Release licensing](legal/release-licensing.md)
- [Building from source](development/building.md)

XGrid ships no firmware, BIOS images, EEPROMs or game data.
