# XGrid 0.1.0

The first alpha release of XGrid: an Avalonia desktop shell around the custom
XGrid core that began from **xemu 0.8.139**.

## Downloads

| Package | Runtime |
| --- | --- |
| `XGrid-frontend-win-x64.zip` | Windows 10/11, x64 — **includes the emulator** |
| `XGrid-frontend-linux-x64.tar.gz` | Linux x64 — **includes the standalone core** |
| `XGrid-frontend-osx-x64.tar.gz` | macOS Intel — shell only |
| `XGrid-frontend-osx-arm64.tar.gz` | macOS Apple Silicon — shell only |
| `XGrid-cli-<rid>.zip` / `.tar.gz` | Validation CLI |

Every archive is self-contained: no .NET runtime is required. The Linux core
uses the host's SDL3, GLib, libepoxy, zstd and other system libraries. Each
archive carries `COPYING`, `LICENSE`, `THIRD_PARTY_NOTICES.md`, `README.md`,
this file as `RELEASE-NOTES.md` and `VERSION`. Checksums and
`package-manifest.json` are published beside the archives.

## Highlights

- **One application.** The shell loads the core library on Windows, embeds the
  core's picture in the Home page and supplies mapped pads for players 1–4. The
  separate-process host remains available.
- **The retail boot chain.** MCPX ROM → 1BL → 2BL → kernel → dashboard, with the
  NV2A, APU/DSP, ACI, IDE/ATAPI, USB/OHCI and SMBus devices.
- **Real-time media.** ISO/XISO, compressed CHD, CCI (single or split) and
  ZArchive (entry form or file tree) discs, with no extraction step.
- **A real shell.** Library scanning, search, filters, sorts, favorites, play
  time, local and online covers, tabbed settings, per-title overrides,
  keyboard/XInput mapping, display filters, save states, screenshots, Activity
  log and accent themes.
- **In-process core.** Save states, pause/step, 4× fast-forward, live disc swap
  and core-side screenshots; the separate-process mode is the fallback.
- **Sega Chihiro.** The core boots Chihiro netboot images with the media board,
  DIMM, JVS, drive boards, card readers, force feedback and two-to-four linked
  cabinets. Settings cover the cabinet keys, card files, gun pointers and the
  Gundam cockpit.

## Quick start

1. Start `XGrid.Frontend.Avalonia`.
2. In **Settings → System**, configure the BIOS, MCPX ROM, EEPROM and HDD image.
3. Add game folders in **Settings → Library**.
4. Pick a title in **Library**, or press **Power on** for the dashboard.

`F5` powers the console on or off, `P` pauses, `F6`/`F7` save/load the selected
state, `F8` saves a screenshot, `F11` toggles fullscreen, and `Space` toggles 4×
fast-forward. In fullscreen, `Esc` pauses a game and a second press closes XGrid.

## Known limitations

- **Windows has the full shell integration.** Save states, pause/step,
  fast-forward, live disc swap, shell-mapped pads and window embedding need the
  Windows in-process core. The Linux archive bundles the standalone core, which
  owns its window; the macOS archives contain the shell only and need an external
  xemu 0.8.139 build.
- **Real-game compatibility is early.** Treat the
  [compatibility page](../reference/compatibility.md) as the supported surface,
  not “any Xbox disc”.
- **Save states, pause/step, fast-forward and disc swap need in-process hosting.**
- **QEMU state is single-use in-process.** A later launch falls back to a separate
  process until XGrid restarts.
- **No shell netplay UI.**
- **Chihiro audio is incomplete.** Upstream xemu's Chihiro audio path can be
  silent; MJ2/MJ3 also need their own network server.
- **No OS installer.** The archives are portable.
- **Unsigned binaries.** macOS quarantines downloaded archives until
  `xattr -dr com.apple.quarantine <folder>` is run; Windows SmartScreen warns.
