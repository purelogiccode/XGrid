# XGrid 0.1.0

First packaged release. XGrid is a cross-platform original Xbox emulator in
C#/.NET, built from the real console chain (MCPX ROM -> 1BL -> 2BL -> kernel ->
XBE) with no HLE kernel shortcuts.

## Downloads

| Package | Runtime |
|---|---|
| `XGrid-cli-win-x64.zip` / `XGrid-frontend-win-x64.zip` | Windows 10/11, x64 |
| `XGrid-cli-linux-x64.tar.gz` / `XGrid-frontend-linux-x64.tar.gz` | glibc Linux, x64 |
| `XGrid-cli-osx-x64.tar.gz` / `XGrid-frontend-osx-x64.tar.gz` | macOS 11+, Intel |
| `XGrid-cli-osx-arm64.tar.gz` / `XGrid-frontend-osx-arm64.tar.gz` | macOS 11+, Apple Silicon |

Every archive is self-contained: no .NET runtime has to be installed. The same
folder carries `COPYING`, `LICENSE`, `THIRD_PARTY_NOTICES.md`, `README.md`, this
file as `RELEASE-NOTES.md`, and a `VERSION` file. `SHA256SUMS-<rid>.txt`,
`SHA256SUMS.txt` and `package-manifest.json` are published beside the archives.

## Quick start

XGrid ships no firmware, no EEPROM and no game data; supply your own legally
obtained files.

```text
XGrid.Cli boot --bios <bios.bin> --mcpx <mcpx_1.0.bin> --eeprom <eeprom.bin> --hdd <hdd.qcow2>
XGrid.Cli boot --bios <bios.bin> --mcpx <mcpx_1.0.bin> --eeprom <eeprom.bin> --dvd <disc.iso>
XGrid.Cli --help
```

The Avalonia frontend (`XGrid.Frontend.Avalonia`) is the desktop UI: point it at
the firmware, storage and library paths in **Settings**, then launch a title from
**Library**. `F7` steps one presented frame, `Shift+F7` steps 1,000,000
instructions, `F8`/`F9` save/load a state.

## Highlights

- **Real boot chain**: retail MCPX ROM through the 2BL and the kernel into the
  dashboard XBE; SMC, PCI, IDE (HDD + ATAPI DVD, plain ISO and compressed CHD),
  USB/OHCI with the Xbox hub/XID pad chain, SMBus/EEPROM, RTC, PIT/PIC and the
  NV2A.
- **Two renderers**: a portable software rasterizer (default) that runs the
  vertex-program interpreter, fixed-function stage, combiners, textures,
  zeta/stencil and blend; and a host-OpenGL backend (Windows) in replacement
  mode with the software sampler's filtering and wrap semantics.
- **Two CPU engines**: an accurate interpreter (the gate mode) and a fast raw
  x86-64 block emitter with direct block chaining (`--jit`), used by the
  frontend's fast mode.
- **Audio**: AC'97 (ACI) and the APU voice processor, plus the ported xemu
  0.8.139 GP/EP DSP core, which executes the guest's real microcode and can
  record the EP output FIFO to a 48 kHz/16-bit stereo WAV (`--apu-dsp
  --audio-out mix.wav`).
- **Usability**: save/load states, XInput and keyboard pads, per-title overrides
  (including the renderer), persistent EEPROM, frame stepping, library scan and
  themeable desktop UI.

## Known limitations

- **Host audio is not complete.** The VP mixer (`vp.c`) and the AC'97 codec
  path are not modelled, so the DSP port and the WAV sink are exercised but the
  boots in this release are not yet audible on their own.
- **Real-game compatibility is early.** The compatibility matrix
  (`docs/compatibility.md`) tracks homebrew samples and a few real titles; treat
  those rows as the supported surface, not "any Xbox disc".
- **The OpenGL renderer is Windows-only.** On Linux and macOS the frontend uses
  the software rasterizer; the CLI still accepts `--gpu sw`.
- **No OS installer.** The archives are portable and write only to the per-user
  data directory.
- **Unsigned binaries.** macOS quarantines a downloaded archive until
  `xattr -dr com.apple.quarantine <folder>` is run, and Windows SmartScreen shows
  its uninformed warning. Neither package is code-signed or notarized.
- Performance is not yet xemu-class; the current measured gap and the exact
  workload are recorded in `docs/development-direction.md`.

## Validation

Cut from a tree whose gates pass locally (CI is disabled on this repository):

- `dotnet build XGrid.sln -c Release` with warnings as errors; full test suite
  green; `dotnet format --verify-no-changes` clean.
- Emulator gates at 1B steps: triangle `gl+replace` `4F1FCBC0`/`7DAB63EB`,
  menu `gl+replace` `B06BA6E5`/`F5D61C94`, accurate goldens `A1740DE0` /
  `7A860ED7` (triangle) and `4EF1FBF6` / `B6116DAE` (menu) with
  `BackendUnsupported=0`.
- Kernel test suite smoke: 7/7 rows, suite log byte-identical at
  792,800,535 steps.
- Packages: `scripts/package-verify.ps1` reports `PACKAGE PASS` for all four
  RIDs (license set, archive contents, SHA-256, manifest, CLI version).
